# Multi-Table UX (Foundation)

## Scope delivered
This phase adds a lightweight active-table switcher foundation in the table experience.

## Behavior
- Tracks active table IDs in local storage for quick switching.
- Renders compact active-table list controls in table views.
- Preserves mobile-first compact shell ergonomics.

## UX objectives
- Reduce navigation friction for players sitting in multiple cash/tournament tables.
- Keep controls fast and touch-friendly for mobile portrait usage.

## Current limitations / next steps
- No global websocket-driven active-table roster yet.
- No tile/quad view or drag-to-arrange yet.
- No per-table alert priorities (action needed, all-in, timeout warning) yet.
